
# Kaley's Turismo en Katira

Sitio web informativo desarrollado para promocionar los atractivos turísticos de Katira, Guatuso, Alajuela, Costa Rica.

El sitio presenta información sobre Río Celeste, actividades turísticas, hospedajes y opciones de contacto para visitantes nacionales e internacionales.
El sitio cuenta con diferentes secciones que permiten al usuario explorar el destino de manera sencilla:

- Inicio:
- Atractivos:
- Actividades:
- Hospedaje:
- Contacto:

## Objetivos

- Promocionar los principales atractivos turísticos de Katira, Guatuso, destacando Río Celeste y el Parque Nacional Volcán Tenorio.
- Brindar información sobre actividades recreativas, senderismo, tours y experiencias de turismo rural y ecológico.
- Dar a conocer opciones de hospedaje, como cabañas y hoteles cercanos, para facilitar la planificación del viaje.
- Ofrecer un sitio web optimizado para dispositivos móviles, con buenas prácticas de accesibilidad, seguridad y posicionamiento SEO.
## Features

• Página de inicio con información de Río Celeste.
• Información sobre el Parque Nacional Volcán Tenorio.
• Actividades turísticas.

## Installation

1. Clona este repositorio o descárgalo como archivo ZIP.
```bash
git clone https://github.com/VivianMorenoG/Kaleys-turismo-katira.git
```
2. Abre la carpeta del proyecto en **Visual Studio Code**.
3. Instala las dependencias (si deseas utilizar las variables de entorno del proyecto):
```bash
npm install
```
4. Si es necesario, crea un archivo `.env` tomando como referencia el archivo `.env.example`.
5. Ejecuta el proyecto abriendo el archivo `index.html` en tu navegador o utilizando la extensión **Live Server** de Visual Studio Code.
    
## Usage

Una vez abierto el sitio web, el usuario podrá:

- Explorar información sobre Río Celeste y el Parque Nacional Volcán Tenorio.
- Conocer las actividades turísticas disponibles.
- Consultar opciones de hospedaje.
- Registrarse mediante un formulario seguro con protección Honeypot.
- Navegar desde dispositivos móviles o computadoras gracias al diseño responsive.

## FAQ

#### ¿Qué información ofrece el sitio?

Información sobre Río Celeste, el Parque Nacional Volcán Tenorio, actividades turísticas y opciones de hospedaje en Katira.

#### ¿El sitio es compatible con dispositivos móviles?

Sí. El sitio cuenta con un diseño responsive que se adapta a diferentes tamaños de pantalla.

#### ¿Cómo puedo contactar a Kaley's Turismo?

Mediante el formulario de registro y los enlaces a redes sociales disponibles en el sitio web.
